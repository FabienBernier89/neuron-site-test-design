Troubleshooting

A greyed-out button, a missing language, a translation that does not start, a rejected file: four common problems, their exact cause in the app and how to fix them.

Why is the Next button greyed out?

In Translation projects, the ‘Next’ button only becomes active once the current step is complete. At the ‘Set-up’ step, it stays greyed out until you select a target language. At the ‘File overview’ step, it stays greyed out until you upload a file. At the ‘Quotes’ step, the ‘Generate quote’ button follows the same logic and waits for a due date and a review level.

  1. At the Set-up step, click ‘Select target languages’ and tick at least one target language.
  2. Check that the language tag appears below the button: it is what activates ‘Next’.
  3. At the File overview step, upload at least one file to the upload area before you look for ‘Next’.
  4. At the Quotes step, enter a due date in ‘Due date’ and a level in ‘Review level’.
  5. Then check that the Generate quote button has become active.
Good to know
  • A greyed-out button in Corrext signals missing information, not a fault: the screen is always waiting for a specific entry.
  • If the language you want does not appear in the list, check the confidentiality level chosen at the previous step.
  • The project is created as soon as you move to the ‘File overview’ step, so you do not have to redo the initial set-up.
Why is my target language not available?

If a target language does not appear in the list, the most common cause is ‘Highly sensitive content’ mode. This mode requires exclusively Swiss processing and is only available for German, French, Italian and English. If you switch it off, or choose standard confidentiality in a project, you get back the 30 languages of the platform.

  1. In Text and document translation, find the Highly sensitive content toggle to the right of the tabs and check whether it is on.
  2. Switch it off if your content allows it: the list of target languages reloads with all 30 languages.
  3. In a project, go back to the Set-up step and check which confidentiality card is selected.
  4. Choose Standard confidentiality if the document does not require exclusively Swiss processing.
  5. If the content is confidential, keep sensitive mode and choose one of the four available languages.
Good to know
  • The trade-off between confidentiality and language range is explicit in the app: the sensitive mode card itself lists its four languages.
  • Use the search field of the language list before you conclude that a language is missing: the list is long.
  • A missing language has nothing to do with the engine you chose: it is the confidentiality mode that restricts the list.
Why is my translation not starting?

In the ‘Text translation’ tab, there is no button to start the translation: it happens as you type. If nothing appears in the right-hand pane, first check that the source and target languages are not the same. In that case, the app shows the message ‘Identical source and target languages’. A brief error message may also appear: try the action again.

  1. Check that there is text in the left-hand pane and that the character counter is not at zero.
  2. Compare the two language lists: if they are the same, the target pane shows Identical source and target languages.
  3. Change the target language, or use the swap button between the two lists.
  4. Check that you have not exceeded the character limit of the current tab.
  5. If a brief error message appears, try the action again: the panel usually loads on the second attempt.
  6. In CHnell, remember that the Enter key does not start the search: use the Search button.
Good to know
  • There is deliberately no confirm button: the translation is recalculated each time the source text changes.
  • The regenerate button of the ‘Rephrasing’ tab is there precisely to ask for a new result when the first one is not suitable.
  • The same sentence may return an identical result after regeneration: this is the observed behaviour. In that case, use the ‘Alternatives’ panel.
Why was my file rejected?

When Corrext rejects a file, the cause is almost always one of three things: the format is not on the accepted list, the file is larger than 50 MB, or more than 25 files were uploaded at once. The ‘PDF to Word’ tab adds its own restriction, since it only accepts .pdf. The upload areas show these limits on screen, just below the upload button.

  1. Check the extension: only .pdf, .doc, .docx, .xls, .xlsx, .ppt and .pptx are accepted for translation.
  2. Check that you are not on the PDF to Word tab, which only accepts .pdf.
  3. Check the size of the file: the limit is 50 MB per file.
  4. Count the files in your batch: the limit is 25 files per upload.
  5. Start again from the original file, .docx or .xlsx rather than PDF: it is often smaller and better processed.
  6. Read the text of the upload area, which shows the exact list of formats and the maximum size allowed.
Good to know
  • Format and size are quicker to check than content: always start with these two points.
  • A very large scanned PDF should be converted to Word with the ‘PDF to Word’ tab before anything else.
  • The limits are the same in Text and document translation and in Translation projects: a file rejected by one will be rejected by the other.
