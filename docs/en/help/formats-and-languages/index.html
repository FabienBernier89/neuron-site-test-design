Formats and languages

File formats, number and size of uploads, character limits, available languages: all the platform's limits in one place, as they appear in the app.

Which file formats are accepted?

Corrext accepts seven file formats for translation: .pdf, .doc, .docx, .xls, .xlsx, .ppt and .pptx. This list applies both to the ‘File translation’ tab of Text and document translation and to the ‘File overview’ step of a translation project. The ‘PDF to Word’ tab is the exception: it only accepts .pdf, since its purpose is to convert that format.

  1. Check your file's extension before you upload it: .pdf, .doc, .docx, .xls, .xlsx, .ppt or .pptx.
  2. Use the original format where possible, .docx or .xlsx rather than PDF, as the upload area of a project reminds you.
  3. To convert a PDF into an editable Word document, use the PDF to Word tab, which only accepts .pdf.
  4. Convert any file in another format beforehand: the app will not accept it as it is.
  5. Read the text of the upload areas: they show the exact list of formats accepted in each place.
Good to know
  • A document uploaded as a PDF when the Word version exists loses layout quality: the original format is always preferable.
  • A scanned PDF is not text: convert it to Word before you translate it or have it reviewed.
  • The list of formats is the same for Text and document translation and for Translation projects: a file rejected by one will be rejected by the other.
How many files can I upload, and how large can they be?

The upload areas of Corrext state two limits: up to 25 files per upload, and a maximum of 50 MB per file. They apply to both the ‘File translation’ tab and the ‘PDF to Word’ tab of Text and document translation. The ‘File overview’ step of a translation project also states the limit of 50 MB per file.

  1. Count your files before you upload them: the limit is 25 files per upload.
  2. Check the size of each file: the limit is 50 MB per file, not for the whole batch.
  3. Split a batch that is too large into several successive uploads rather than forcing a single upload.
  4. Reduce the size of a heavy PDF, or go back to the original Word file, which is often much smaller.
  5. Read the limits shown in the upload area of the current tab or step: they are always displayed there.
Good to know
  • A rejected file is more often due to its format or size than to its content: check these two points first.
  • For a translation project, the quote is calculated in standard pages: the number of files matters less than how dense they are.
  • Using the original format often makes the file smaller as well as improving the layout.
What are the character limits?

Text and document translation has two character limits. The ‘Text translation’ tab accepts 10,000 characters, shown by a counter below the input area. The ‘Rephrasing’ tab stops at 5,000 characters. Beyond that, the right approach is not to keep splitting your text, but to use the ‘File translation’ tab, which handles a whole document.

  1. Watch the counter below the input area: it shows the number of characters used and the limit of the tab.
  2. Stay below 10,000 characters for a text translation in the ‘Text translation’ tab.
  3. Stay below 5,000 characters for rephrasing in the ‘Rephrasing’ tab.
  4. Beyond that, save your text in a document and upload it to the File translation tab.
  5. For a long document that needs review, open a project in Translation projects instead.
Good to know
  • The counter updates as you type: you can see immediately when pasted text exceeds the limit.
  • The rephrasing limit is lower than the translation limit: a text you can translate in one go cannot necessarily be rephrased in one go.
  • Splitting a long text loses the context from one sentence to the next: file translation gives a more consistent result.
Which languages are available, and which are native?

Corrext offers 30 target languages on the platform, from English to Japanese, including Arabic, Chinese, Polish and Turkish. Four of them are native and cover the languages of Swiss legal work: German, French, Italian and English. ‘Highly sensitive content’ mode restricts the choice to these four languages, because processing must then stay in Switzerland.

  1. Open the target language list in Text and document translation, or the ‘Select target languages’ button in a project.
  2. Use the search field of the list to find a language without scrolling through all 30 entries.
  3. For Swiss legal work, choose one of the four native languages where you can: German, French, Italian or English.
  4. Check the ‘Highly sensitive content’ toggle if a language you expect does not appear: it limits the choice to EN, FR, IT and DE.
  5. In a translation project, tick several target languages at once: each one then appears as a tag.
Good to know
  • The 30 languages cover the main European languages and several Asian languages, as well as both variants of Portuguese and of Chinese.
  • The difference between a native language and an available language lies in the depth of legal processing, not just in being on the list.
  • In CHnell, you choose the language pair independently of the one used in your current translation.
Is the layout preserved when I translate a file?

Yes, the translation is delivered in the original format. For a PDF, especially a scan, the PDF to Word tab first produces an editable Word document.
