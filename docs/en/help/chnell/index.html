Fast lookup CHnell

CHnell is a bilingual concordancer: it shows how a term is actually translated in Swiss official texts, segment by segment, with its source and its domain. Here is how to search, filter and read a result.

How do I search for a term in CHnell?

CHnell searches for a word or a phrase in a language pair and returns bilingual segments taken from official sources. Set the source and target languages at the top of the screen. Enter your term in the ‘Search for a word, an expression, a term’ field, then click the ‘Search’ button. The Enter key does not start the search.

  1. Open Fast lookup from the home page: the CHnell screen appears with two language lists.
  2. Set the source and target languages. The swap button between the two lists switches them.
  3. Enter your term in the Search for a word, an expression, a term field.
  4. Click the Search button: the Enter key does not start the search.
  5. Read the results header: it shows the term searched, the language and the number of results found.
  6. Browse the aligned segments, source on the left and target on the right, with the term highlighted in each.
Good to know
  • Each language list has a cross that clears it: use it to start again with an empty language pair.
  • The ‘Show more results’ button at the bottom of the list loads more segments without running the search again.
  • From a translation in progress, the same tool opens directly on a highlighted word, with the ‘Fast Lookup’ button.
Which search operators can I use?

Below the search field, CHnell displays ‘Supported search operators’, followed by the three supported operators: straight quotation marks, the hyphen and the word ‘or’. An information icon next to this line gives the details in the app. You type the operators directly in the search field, before you click ‘Search’.

  1. Open ‘Fast lookup’ and find the Supported search operators line below the search field.
  2. Hover over or click the information icon next to this line to read the exact syntax in the app.
  3. Type your query with the operator you need directly in the search field.
  4. Click Search to run the search, then check the number of results shown in the header.
  5. If the query is too broad, add an operator or use the domain and source filters.
Good to know
  • The app lists the three operators without explaining how to use them on screen. Their full definition is in the information tooltip. It is not reproduced here because it has not been observed.
  • Operators do not replace filters: to restrict results to a domain or a source, use ‘Advanced search’ or the ‘Filters’ panel.
  • Check the language pair before you conclude that a term has no results: sometimes swapping the languages is enough.
How do I filter by domain and source?

CHnell classifies its segments by legal domain and by source. Before you search, the collapsible ‘Advanced search’ block lets you restrict the resource type. It also lets you tick one or more of the 30 available domains, from company law and arbitration to taxation. On the results page, the ‘Filters’ panel repeats these criteria and adds a selection of sources.

  1. On the CHnell screen, expand the Advanced search block above the search field.
  2. Set Resource type to limit the search to one type of resource.
  3. Open Domains and tick the domains you need: the list has 30, from banking law to patent law.
  4. Run the search with the ‘Search’ button.
  5. On the results page, expand the Filters panel to adjust the same criteria without entering everything again.
  6. Use Select sources in this panel to keep only certain sources, for example federal texts.
Good to know
  • The domain of each segment is shown in capitals above the text: it is the quickest way to judge whether a result is relevant.
  • Filtering by source is useful when several authorities use different wording for the same concept.
  • The full list of 30 domains opens in the app: it covers company law as well as criminal law and taxation.
What is the difference between shared resources and own resources?

In ‘Advanced search’, the ‘Resource type’ filter offers three values: ‘All resources’, ‘Shared resources’ and ‘Own resources’. Shared resources are the text collections available to all CHnell users. Own resources are those linked to your organisation. The filter therefore lets you search either everywhere or only in your organisation's own material.

  1. Expand Advanced search on the CHnell screen.
  2. Open the Resource type filter and read the three values offered.
  3. Choose All resources to search both the shared collections and your organisation's own collections.
  4. Choose Shared resources to keep only the shared collections, which are useful for citing official usage.
  5. Choose Own resources to search only the resources specific to your organisation.
  6. Run the search with ‘Search’ and check the number of results, which varies widely with this filter.
Good to know
  • Adding and managing own resources could not be observed from a standard user account, so these tasks are not documented here. Ask your administrator.
  • If ‘Own resources’ returns no results, your organisation probably has no own resources linked to it yet.
  • Shared resources come from public Swiss texts: their source is shown below each segment, which makes them citable.
How do I see a segment in its context?

Each CHnell result is an aligned segment: the source sentence on the left and its translation on the right, with the searched term highlighted in both. The legal domain appears above it in capitals, and the exact source of the text below it, for example a federal compilation or an authority's website. The ‘Show in context’ link opens the segment in its original setting, so you can check that it really matches your case.

  1. Run a search in CHnell and browse the list of aligned segments.
  2. Find the highlighted term in the source sentence and in the target sentence: this is the match to assess.
  3. Read the domain label in capitals above the segment to check that it belongs to the right field of law.
  4. Read the source line below the segment: it names the original text and the dataset it comes from.
  5. Click Show in context to open the segment in its full context.
  6. Click Show more results at the bottom of the list to load more segments.
Good to know
  • A term can have several correct translations depending on the domain: the domain label, not the number of results, settles the question.
  • The source reference is what makes a usage citable: note it if you need to justify a terminology choice.
  • The total number of results is shown in the page header: a high figure suggests filtering rather than reading everything.
