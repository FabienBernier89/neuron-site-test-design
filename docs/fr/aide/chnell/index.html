Fast lookup CHnell

CHnell est un concordancier bilingue : il montre comment un terme est réellement traduit dans des textes officiels suisses, segment par segment, avec sa source et son domaine. Voici comment chercher, filtrer et lire un résultat.

Comment rechercher un terme dans CHnell ?

CHnell cherche un mot ou une expression dans un couple de langues et renvoie des segments bilingues tirés de sources officielles. Vous réglez la langue de départ et la langue d'arrivée en haut de l'écran, vous saisissez votre terme dans le champ « Search for a word, an expression, a term », puis vous cliquez sur le bouton « Search ». La touche Entrée ne déclenche pas la recherche.

  1. Ouvrez « Fast lookup » depuis l'accueil : l'écran CHnell s'affiche avec deux listes de langues.
  2. Réglez la langue de départ et la langue d'arrivée ; le bouton d'inversion entre les deux listes les permute.
  3. Saisissez votre terme dans le champ « Search for a word, an expression, a term ».
  4. Cliquez sur le bouton « Search » : la touche Entrée ne lance pas la recherche.
  5. Lisez l'en-tête des résultats : il rappelle le terme cherché, la langue et le nombre de résultats trouvés.
  6. Parcourez les segments alignés, source à gauche et cible à droite, avec le terme surligné dans chacun.
À savoir
  • Chaque liste de langues porte une croix d'effacement : elle sert à repartir d'un couple de langues vide.
  • Le bouton « Show more results » en bas de la liste charge la suite des segments sans relancer la recherche.
  • Depuis une traduction en cours, le même outil s'ouvre directement sur un mot surligné, grâce au bouton « Fast Lookup ».
Quels opérateurs de recherche puis-je utiliser ?

Sous le champ de recherche, CHnell affiche la mention « Supported search operators », suivie des trois opérateurs pris en charge : les guillemets droits, le tiret et le mot or. Une icône d'information placée à côté de cette mention donne le détail dans l'application. Les opérateurs se saisissent directement dans le champ de recherche, avant de cliquer sur « Search ».

  1. Ouvrez « Fast lookup » et repérez la ligne « Supported search operators » sous le champ de recherche.
  2. Survolez ou cliquez l'icône d'information à côté de cette ligne pour lire la syntaxe exacte dans l'application.
  3. Saisissez votre requête avec l'opérateur voulu directement dans le champ de recherche.
  4. Cliquez sur « Search » pour lancer la recherche, puis vérifiez le nombre de résultats affiché en en-tête.
  5. Si la requête est trop large, ajoutez un opérateur ou passez par les filtres de domaine et de source.
À savoir
  • L'application liste les trois opérateurs sans en détailler l'emploi à l'écran : leur définition complète se lit dans l'infobulle d'information, et n'est pas reprise ici faute d'avoir été observée.
  • Les opérateurs ne remplacent pas les filtres : pour restreindre à un domaine ou à une source, utilisez « Advanced search » ou le panneau « Filters ».
  • Pensez à vérifier le couple de langues avant de conclure qu'un terme n'a pas de résultat : une inversion suffit parfois.
Comment filtrer par domaine et par source ?

CHnell classe ses segments par domaine juridique et par source. Avant de chercher, le bloc repliable « Advanced search » permet de restreindre le type de ressource et de cocher un ou plusieurs domaines parmi les 30 disponibles, du droit des sociétés à la fiscalité en passant par l'arbitrage. Sur la page de résultats, le panneau « Filters » reprend ces critères et y ajoute la sélection des sources.

  1. Sur l'écran CHnell, dépliez le bloc « Advanced search » au-dessus du champ de recherche.
  2. Réglez « Resource type » pour limiter la recherche à un type de ressource.
  3. Ouvrez « Domains » et cochez les domaines utiles : la liste en compte 30, du droit bancaire au droit des brevets.
  4. Lancez la recherche avec le bouton « Search ».
  5. Sur la page de résultats, dépliez le panneau « Filters » pour ajuster les mêmes critères sans tout ressaisir.
  6. Utilisez « Select sources » dans ce panneau pour ne garder que certaines sources, par exemple les textes fédéraux.
À savoir
  • Le domaine de chaque segment est affiché en capitales au-dessus du texte : c'est le moyen le plus rapide de juger si un résultat est pertinent.
  • Filtrer par source est utile quand plusieurs autorités emploient des formulations différentes pour un même concept.
  • La liste complète des 30 domaines s'ouvre dans l'application : elle couvre aussi bien le droit des sociétés que le droit pénal ou la fiscalité.
Quelle différence entre ressources partagées et ressources propres ?

Dans « Advanced search », le filtre « Resource type » propose trois valeurs : « All resources », « Shared resources » et « Own resources ». Les ressources partagées sont les corpus mis à disposition de tous les utilisateurs de CHnell ; les ressources propres sont celles rattachées à votre organisation. Le filtre permet donc de chercher soit partout, soit uniquement dans le patrimoine de votre organisation.

  1. Dépliez « Advanced search » sur l'écran CHnell.
  2. Ouvrez le filtre « Resource type » et lisez les trois valeurs proposées.
  3. Choisissez « All resources » pour chercher à la fois dans les corpus partagés et dans ceux de votre organisation.
  4. Choisissez « Shared resources » pour ne retenir que les corpus partagés, utiles pour citer un usage officiel.
  5. Choisissez « Own resources » pour ne chercher que dans les ressources propres à votre organisation.
  6. Lancez la recherche avec « Search » et vérifiez le nombre de résultats, qui varie fortement selon ce filtre.
À savoir
  • L'ajout et la gestion des ressources propres n'ont pas été observés depuis un compte utilisateur standard : cette administration n'est pas documentée ici, demandez-la à votre administrateur.
  • Si « Own resources » ne renvoie aucun résultat, c'est probablement qu'aucune ressource propre n'est encore rattachée à votre organisation.
  • Les ressources partagées proviennent de textes publics suisses : leur source est indiquée sous chaque segment, ce qui les rend citables.
Comment afficher un segment dans son contexte ?

Chaque résultat de CHnell est un segment aligné : la phrase source à gauche, sa traduction à droite, avec le terme cherché surligné dans les deux. Au-dessus figure le domaine juridique en capitales, en dessous la source exacte du texte, par exemple un recueil fédéral ou le site d'une autorité. Le lien « Show in context » ouvre le segment dans son environnement d'origine, pour vérifier qu'il correspond bien à votre cas.

  1. Lancez une recherche dans CHnell et parcourez la liste de segments alignés.
  2. Repérez le terme surligné dans la phrase source et dans la phrase cible : c'est la correspondance à évaluer.
  3. Lisez l'étiquette de domaine en capitales au-dessus du segment pour vérifier qu'il relève du bon champ du droit.
  4. Lisez la ligne de source sous le segment : elle nomme le texte d'origine et le jeu de données dont il provient.
  5. Cliquez sur « Show in context » pour ouvrir le segment dans son contexte complet.
  6. Cliquez sur « Show more results » en bas de la liste pour charger d'autres segments.
À savoir
  • Un terme peut avoir plusieurs traductions correctes selon le domaine : c'est l'étiquette de domaine, pas le nombre de résultats, qui tranche.
  • La mention de la source est ce qui rend un usage citable : notez-la si vous devez justifier un choix terminologique.
  • Le nombre total de résultats est affiché en en-tête de la page : un chiffre élevé invite à filtrer plutôt qu'à tout lire.
