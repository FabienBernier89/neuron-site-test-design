Was der Lektorats-Editor genau macht

Ein CAT-Tool zerlegt das Dokument in Segmente. Ein Segment ist ein Satz oder ein Titel. Sie lektorieren jedes Segment neben dem Original, korrigieren es bei Bedarf und bestätigen es dann.

Lektorieren

Zwei Spalten

Links das Original, rechts die Übersetzung, Segment für Segment. Ein Suchfilter über jeder Spalte findet einen Satz im Ausgangstext oder in der Übersetzung.

Lektorieren

Herkunft jedes Satzes

Eine Anzeige zeigt, ob die Übersetzung vom Motor oder aus dem Translation Memory stammt. Bei maschineller Übersetzung gibt eine Skala die Qualitätsstufe an: niedrig, mittel oder hoch.

Lektorieren

Bestätigung

Ein Kontrollkästchen pro Segment bestätigt das Lektorat. Der Fortschritt des Dokuments erscheint in Prozent oben im Editor.

Lektorieren

Werkzeugleiste

Formatierungs-Tags (öffnend, schliessend, eigenständig), fett, kursiv, unterstrichen und Kopie des Ausgangstexts in die Übersetzung.

Prüfen

Prüfungen

Der Editor erkennt wiederholte Sätze und inkonsistente Tags.

Prüfen

Translation Memorys

Für den gewählten Satz die ähnlichsten bereits freigegebenen Übersetzungen. Ein Klick auf Apply übernimmt sie in die Übersetzung.

Prüfen

Fast Lookup

Live-Suche in Ihren Translation Memorys und in CHnell, im Ausgangs- oder Zieltext. Jedes Ergebnis ist zweisprachig, der Begriff ist auf beiden Seiten markiert, und das Originaldokument wird angegeben.

Prüfen

KI-Assistent

Alternatives: derselbe Satz, von mehreren Motoren übersetzt, nebeneinander, weitere auf Anfrage. Rephrasing: eine Umformulierung in fünf Stilen (formell juristisch, finanziell, vereinfacht, formell, informell), mit einer Option zum Kürzen.

Teilen und nachverfolgen

Sync

Für das Lektorat im Team: Konflikte zwischen zwei Fassungen, über die zu entscheiden ist, Änderungen einer Kollegin oder eines Kollegen, die zu übernehmen sind, und die Übertragung einer Korrektur auf identische Sätze.

Teilen und nachverfolgen

Dashboard

Vertraulichkeit, Art des Lektorats, Sprachen, Fortschritt, Referenzdateien, Anweisungen, Translation Memorys und Team. Für jede Datei: Open in CAT, Preview, Export docx, Reimport docx, Download TMX und Validate.

Fliessen Ihre Korrekturen in Ihre nächsten Übersetzungen ein?

Ja, bei Standard-Vertraulichkeit. Jede Korrektur im Editor wird in Ihrem Translation Memory gespeichert. Beim nächsten Projekt übernimmt Corrext sie. So passt sich die Übersetzung Projekt für Projekt an Ihren Schreibstil an. Und dieselbe Passage wird von Projekt zu Projekt gleich übersetzt.

Sicherheit und Datensouveränität

Von der hochgeladenen Datei zum freigegebenen Dokument

Das Lektorat ist ein Schritt eines Projekts in Corrext. Hier der vollständige Ablauf, in der Reihenfolge der Anwendung. Die ersten vier Schritte erfolgen beim Erstellen des Projekts.

  1. 01Projekt

    Projekt erstellen

    Name, Zielsprachen, Vertraulichkeitsniveau und ob die Kommentare im Dokument übersetzt werden.

  2. 02Projekt

    Analyse der Dateien

    Jede Datei wird in Normseiten gezählt. Eine Normseite umfasst 1'800 Zeichen inklusive Leerzeichen.

  3. 03Projekt

    Terminologie des Projekts

    Corrext extrahiert selbst die Begriffskandidaten aus dem Dokument. Sie legen deren Übersetzung fest oder fügen eigene Begriffe hinzu.

  4. 04Projekt

    Wahl des Motors

    LexMachina, zu 100 % aus der Schweiz, oder ein von Ihrer Organisation zugelassener Motor eines Drittanbieters: DeepL Pro, Azure OpenAI GPT, Claude. Die Motoren von Drittanbietern werden im Ausland gehostet.

  5. 05Motor

    Maschinelle Übersetzung

    Der gewählte Motor übersetzt das Dokument. Die in Schritt 3 festgelegten Begriffe werden unverändert übernommen.

  6. 06Editor

    Lektorat im Editor

    Open in CAT: Sie lektorieren, korrigieren und bestätigen jeden Satz, allein oder im Team.

  7. 07Dashboard

    Freigabe

    Die lektorierte Datei wird im Dashboard des Projekts freigegeben.

  8. 08Dashboard

    Export

    Das übersetzte Dokument wird als Word-Datei exportiert. Das Translation Memory der Datei lässt sich im Format TMX herunterladen.

In Word arbeiten

Das Lektorat ist auch in Microsoft Word möglich. Exportieren Sie das Dokument im Dashboard des Projekts (Export docx). Öffnen Sie es in Word mit dem Add-in Corrext: KI-Assistent, Fast Lookup, Translation Memorys und Sync finden Sie dort in einem Aufgabenbereich. Nach dem Lektorat importieren Sie die Datei wieder (Reimport docx).

Häufige Fragen zum Lektorats-Editor

Was ist ein CAT-Tool?

CAT steht für «Computer-Assisted Translation», auf Deutsch computergestützte Übersetzung. Ein solches Tool zerlegt das Dokument in Segmente, also in Sätze oder Titel, und stellt jedes neben seine Übersetzung. Die lektorierende Person korrigiert und bestätigt jedes Segment, unterstützt durch Translation Memorys und Terminologie. In Corrext heisst dieses Tool Lektorats-Editor.

Wie öffne ich den Lektorats-Editor?

Über das Dashboard eines Projekts. Jede Datei hat dort eine Schaltfläche Open in CAT, die das Dokument im Editor öffnet. Das Projekt selbst erstellen Sie im Projektmanagement: Sprachen, Vertraulichkeitsniveau, Terminologie und Übersetzungsmotor.

Fliessen meine Korrekturen in die nächsten Übersetzungen ein?

Ja, bei Standard-Vertraulichkeit. Ihre Projekte bleiben auf den Schweizer Servern von Corrext und dienen nur Ihnen als Translation Memory. Eine Korrektur von heute wird in Ihren nächsten Projekten übernommen. So passt sich die Übersetzung an Ihre Sprache an und bleibt von Projekt zu Projekt einheitlich.

Und im Modus für hochsensible Inhalte?

In diesem Modus (Highly sensitive content) fliessen die Übersetzungen nicht ins Translation Memory. Die Daten werden ausschliesslich in der Schweiz gespeichert und verarbeitet. Der Modus ist auf Deutsch, Französisch, Italienisch und Englisch verfügbar. Sie wählen ihn beim Erstellen jedes Projekts.

Können mehrere Personen dasselbe Dokument lektorieren?

Ja. Die Registerkarte Sync organisiert die Arbeit im Team. Sie zeigt Konflikte zwischen zwei Fassungen desselben Satzes, über die zu entscheiden ist. Sie listet die Änderungen einer Kollegin oder eines Kollegen auf, die zu übernehmen sind. Und sie schlägt vor, eine Korrektur auf identische Sätze im Dokument zu übertragen: die Propagation. Das Projektteam verwalten Sie im Dashboard.

Brauche ich Microsoft Word für das Lektorat?

Nein. Den Lektorats-Editor nutzen Sie direkt in Corrext. Wenn Sie lieber in Word arbeiten, exportieren Sie das Dokument im Dashboard (Export docx), lektorieren es mit dem Add-in Corrext und importieren es wieder (Reimport docx). Das Add-in erfordert eine Anmeldung, die Mitgliedschaft im Projekt und Office 2021 oder Microsoft 365.

Werden die von mir festgelegten Begriffe eingehalten?

Ja. Beim Erstellen des Projekts extrahiert Corrext selbst die Begriffskandidaten aus dem Dokument. Sie legen deren Übersetzung fest oder fügen eigene Begriffe hinzu. Ein festgelegter Begriff wird unverändert in die maschinelle Übersetzung übernommen, die Sie danach im Editor lektorieren.

Welche Dateiformate kann ich lektorieren?

Die Formate, die Sie in ein Projekt hochladen: .pdf, .doc, .docx, .xls, .xlsx, .ppt und .pptx, bis 50 MB pro Datei. Die Anwendung empfiehlt das Originalformat statt PDF. Im Dashboard exportieren Sie das lektorierte Dokument als Word-Datei, und sein Translation Memory laden Sie im Format TMX herunter, dem Standardformat für den Austausch von Translation Memorys.
