Les fonctions de l'éditeur de relecture, dans Word

Vous exportez le document de votre projet Corrext, puis vous le relisez dans Word. Le panneau reprend les fonctions de l'éditeur de relecture. Une fois la relecture terminée, vous réimportez le fichier dans le projet.

Segments

Source et cible côte à côte, segment par segment. Un segment, c'est une phrase ou un titre.

Mémoire de traduction

Corrext affiche les traductions déjà validées les plus proches du segment choisi. Un clic sur Apply les reprend dans la traduction.

Fast Lookup et CHnell

Recherche en direct dans vos mémoires et dans CHnell, côté source ou côté cible. Chaque résultat est bilingue, avec son document d'origine.

Alternatives par moteur

La même phrase traduite par plusieurs moteurs, côte à côte : LexMachina et les moteurs tiers autorisés par votre organisation. D'autres alternatives sur demande.

Harmonisation des termes

L'assistant IA détecte un changement de terme. Il propose de l'harmoniser dans tout le document.

Confirmation et progression

Une case par segment confirme sa relecture. La progression du document s'affiche en pourcentage.

Installé sur votre poste, relié à votre projet

Le plugin Word est un complément installé sur le poste de l'utilisateur. Ce n'est pas un complément de la boutique Microsoft. Il s'ouvre sur un document exporté de votre projet Corrext. Il faut être membre du projet et disposer de Word 2021 ou de Microsoft 365.

  1. 01

    Export docx

    Dans le tableau de bord du projet, exportez le fichier à relire.

  2. 02

    Bouton Corrext

    Ouvrez le fichier dans Word. Le bouton Corrext du ruban affiche le panneau Corrext editor.

  3. 03

    Relecture

    Relisez avec les onglets AI Assistant, Fast Lookup, Matches et Sync. Connectez-vous si le panneau le demande.

  4. 04

    Reimport docx

    Enregistrez le document, puis réimportez-le dans le projet.

Questions fréquentes sur le plugin Word

Le plugin Word est-il un complément de la boutique Microsoft ?

Non. Le plugin Word est installé sur le poste de l'utilisateur. Il ne passe pas par la boutique des compléments Microsoft.

Que faut-il pour utiliser le plugin Word ?

Word 2021 ou Microsoft 365, et un accès au projet Corrext : il faut en être membre. Le panneau demande une connexion.

Le plugin a-t-il les mêmes fonctions que l'éditeur de relecture ?

Oui. Le panneau reprend la mémoire de traduction, Fast Lookup dans CHnell, les alternatives par moteur et l'assistant IA. Vous confirmez chaque segment, et la progression du document s'affiche. L'onglet Sync sert à relire à plusieurs.

Quels documents peut-on relire dans Word ?

Un document exporté d'un projet Corrext avec Export docx. Un fichier issu de la traduction rapide est refusé. Après la relecture, vous réimportez le fichier dans le projet avec Reimport docx.
